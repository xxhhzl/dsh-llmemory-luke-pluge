# 真实 DSH 端到端验收手册

## 执行责任

真实 DSH 验收由用户执行。本仓库提供测试输入、预期结果和记录模板；模拟外壳测试不能替代本验收。

## 环境记录

执行前记录 DSH、插件、Python、Node、文本模型、Embedding 模型及第三方插件版本，使用独立 profile、临时数据库和非生产会话。

## 验收场景

1. 安装并重启 DSH，确认插件版本与 `VERSION` 一致，七个工具全部注册。
2. 新建会话写入事实、偏好和具体命令，等待自动切分并核对数据库。
3. 分别验证原词搜索、同义语义搜索、跨会话时间回放和 `memory_get` 细节读取。
4. 两个会话交错操作，确认被动召回不串会话、不重复注入当前可见事件。
5. 标记 wrong/outdated，确认状态、FTS、向量和 ANN 均退出召回。
6. 在投递回执后、完成前终止内核，确认重启补投且不重复入库。
7. 停止 Embedding 端点，确认词法降级可用；恢复后重建向量索引。
8. 在设置页、右侧栏、维护区和日志页完成逻辑操作及截图校验。

## 三层证据

每个场景同时保存：宿主层工具调用与最终回答、插件层日志与协议状态、数据库层行与索引状态。记录写入 `test/docs/真实DSH端到端验收-YYYYMMDD-HHMM.md`。

## 通过条件

消息丢失、重复入库、会话串扰、过期记忆泄漏和当前上下文重复注入均为零；其余结果满足 `tests/eval/thresholds.json` 与性能门槛。失败项必须包含复现步骤、日志时间点和数据库快照位置。
